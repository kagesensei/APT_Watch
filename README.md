# APT_Watch

Ingests MITRE ATT&CK Enterprise data into a local DuckDB database for querying
threat actors, their techniques, the software they use, and technique
mitigations.

## Setup

Requires Python 3.10+.

```bash
git clone https://github.com/kagesensei/APT_Watch.git
cd APT_Watch
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # macOS/Linux
pip install -r requirements.txt
```

## Usage

Run the ingest pipeline:

```bash
python ingest/attack.py
```

This downloads the latest [ATT&CK Enterprise STIX bundle](https://github.com/mitre-attack/attack-stix-data)
to `data/raw/`, loads it with `mitreattack-python`, and builds `data/cti.duckdb`
with four tables:

| table | description |
|---|---|
| `actor` | ATT&CK groups (intrusion sets) |
| `actor_technique` | techniques used by each actor |
| `actor_software` | software (malware/tools) used by each actor |
| `technique_mitigation` | mitigations mapped to each technique |

Revoked and deprecated ATT&CK objects are excluded. After loading, the
script prints row counts and runs a data quality check comparing table
counts against MITRE's published entity totals, exiting non-zero if any
check fails.

Query the result with any DuckDB client, e.g.:

```bash
python -c "import duckdb; print(duckdb.connect('data/cti.duckdb').sql('SELECT * FROM actor LIMIT 5'))"
```

## Project layout

- `ingest/attack.py` — MITRE ATT&CK ingest pipeline (implemented)
- `ingest/feeds.py`, `ingest/malpedia.py`, `ingest/misp_galaxy.py` — additional
  intel source ingests (not yet implemented)
- `resolve/aliases.py` — actor alias resolution across sources (not yet implemented)
- `model/schema.sql` — target database schema (not yet implemented)
- `data/cti.duckdb` — built database, committed as a snapshot
- `data/raw/` — downloaded source data (regenerated by ingest scripts, not committed)
